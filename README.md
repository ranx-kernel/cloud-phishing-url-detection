# Cloud-Based Phishing URL Detection

## 📌 Project Overview

This project uses machine learning to classify URLs based on URL-related characteristics.

The project is developed using Google Colab as a cloud-based computational environment.

## 🎯 Objectives

- Detect potentially suspicious URLs
- Extract URL-related features
- Train a machine learning classification model
- Evaluate model performance
- Generate phishing risk predictions

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Random Forest

## 📊 Dataset

The dataset contains URL-related features such as:

- URL length
- HTTPS usage
- Number of dots
- Number of hyphens
- Number of subdomains/WWW occurrences
- Sensitive word count
- Special characters

## 🤖 Machine Learning Model

A Random Forest Classifier is used for classification.

## 📈 Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC

## ☁️ Cloud Computing Component

Google Colab provides the cloud-based environment used for:

- Data processing
- Machine learning model training
- Model evaluation
- Prediction

## ⚠️ Disclaimer

This project is an academic prototype and should not be considered a production-grade phishing detection system.
